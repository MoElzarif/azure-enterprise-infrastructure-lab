## Project Overview

This project demonstrates the deployment of a small enterprise Azure infrastructure following common cloud administration practices.

The environment includes:

- Resource Group
- Azure Virtual Network
- Three Subnets
- Network Security Groups
- Windows Server 2025 Virtual Machine
- Ubuntu Linux 24.04 Virtual Machine
- Nginx Web Server
- Azure Monitor Alert
- Azure Backup
- Technical Documentation
